```
- Logo（教材商城）
```

```
左侧菜单：
- 仪表盘 → /admin/dashboard

- 分类管理 → /admin/categories
- 订单管理 → /admin/orders

顶部：
```

**公共页面：**

| 页面 | 路由 | 触发条件 |
|------|------|---------|
| 登录 | `/login` | 未登录时访问保护页面 |
| 管理员登录 | `/admin/login` | 未登录时访问管理端 |
| 403 | `/403` | 已登录但无权限 |
| 404 | `/404` | 路径不存在 |
| 500 | `/500` | 系统异常 |

**关键业务跳转：**

| 从 | 到 | 触发 |
|----|----|------|
| 教材详情 | 购物车 | 点击"加入购物车" |
| 购物车 | 确认订单 | 点击"去结算" |
| 确认订单 | 我的订单 | 提交订单成功 |
| 我的订单 | 订单详情 | 点击"查看详情" |
| 订单详情 | 我的订单 | 点击"返回" |
