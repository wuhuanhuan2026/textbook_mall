| 未登录 | 加入购物车 | 否 | 点击跳登录 |
| 可购买 | 加入购物车 | 否 | 正常加入 |
| 已售罄 | 已售罄 | 是 | 灰色 |
| 库存不足 | 加入购物车 | 否 | 数量上限=库存 |
| 教材下架 | 教材未上架 | 是 | 灰色 |

- 学生不打开详情也能判断教材价格和库存。

- 成功反馈说明下一步去哪里查看记录。

**实际结果：**
- ✅ 教材列表原型已设计。
- ✅ 教材详情原型已设计。

**常见错误与定位方法：**
- 列表卡片信息过多时保留决策所需字段。
- 按钮状态只靠颜色区分时补充文字和aria属性。

**表单校验规则：**

```javascript
function validate(publish = false) {
  errors.value = {}
  if (!form.title.trim()) errors.value.title = '请输入教材标题'
  if (form.price <= 0) errors.value.price = '价格必须大于0'
  if (form.stock < 0) errors.value.stock = '库存不能为负数'
  if (publish && !form.author.trim()) errors.value.author = '上架前必须填写作者'
  if (publish && !form.categoryId) errors.value.categoryId = '上架前必须选择分类'
  return Object.keys(errors.value).length === 0
}
```
