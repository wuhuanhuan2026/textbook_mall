**页面层级结构：**

**学生端：**

```
首页 /
├── 教材列表 /books
│   ├── 教材详情 /book/:id
│   │   └── 加入购物车 → 购物车 /cart
│   │       └── 确认订单 /orders/create
│   │           └── 我的订单 /orders
│   │               └── 订单详情 /order/:id
│   ├── 我的订单 /orders
│   └── 个人中心 /profile
│       └── 地址管理 /address
└── 登录 /login
    └── 注册 /register
```

**管理端：**

```
管理员登录 /admin/login
└── 管理后台 /admin
    ├── 仪表盘 /admin/dashboard
    ├── 教材管理 /admin/books
    ├── 分类管理 /admin/categories
    ├── 订单管理 /admin/orders
    ├── 管理员管理 /admin/users
    ├── 用户管理 /admin/members
    └── 个人信息 /admin/profile
```

**页面层级深度：**

| 页面 | 层级 | 入口 | 返回路径 |
|------|------|------|---------|
| 首页 | 0 | 直接访问 | - |
| 教材列表 | 1 | 首页 | 首页 |
| 教材详情 | 2 | 教材列表 | 教材列表 |
| 购物车 | 1 | 顶部导航 | 首页 |
| 确认订单 | 2 | 购物车 | 购物车 |
| 我的订单 | 1 | 顶部导航 | 首页 |
| 订单详情 | 2 | 我的订单 | 我的订单 |
| 个人中心 | 1 | 顶部导航 | 首页 |
| 地址管理 | 2 | 个人中心 | 个人中心 |

**预期结果与人工检查：**
- 核心功能不超过三次操作即可到达。
- 页面名称与功能清单一致。
- 不存在只有URL而没有入口的页面。

**实际结果：**
- ✅ 学生端页面层级已绘制（3 层）。
- ✅ 管理端页面层级已绘制（2 层）。
- ✅ 核心功能不超过 3 次点击。
- ✅ 深层页面有返回路径。

**常见错误与定位方法：**
- 按数据库表建立菜单会偏离用户任务。
- 把所有功能放到首页会造成导航混乱。
