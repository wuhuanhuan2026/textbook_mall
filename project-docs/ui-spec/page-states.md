**页面状态表（列表页）：**

| 状态 | 触发条件 | 界面表现 | 按钮行为 | 退出条件 |
|------|---------|---------|---------|---------|
| 加载中 | 请求发出 | 骨架屏 | 全部禁用 | 请求返回 |
| 空数据 | 无记录 | 空状态提示 + 创建入口 | 创建按钮可点 | 用户创建 |
| 无筛选结果 | 筛选后无记录 | "未找到匹配教材" + 清空筛选 | 清空按钮可点 | 用户清空筛选 |
| 错误 | 请求失败 | 错误提示 + 重试按钮 | 重试按钮可点 | 用户重试成功 |
| 正常 | 有数据 | 列表展示 | 可操作 | - |

**页面状态表（表单页）：**

| 状态 | 触发条件 | 界面表现 | 按钮行为 |
|------|---------|---------|---------|
| 空闲 | 页面初始 | 表单可编辑 | 提交按钮可点 |
| 提交中 | 点击提交 | 按钮文案"提交中..." | 全部禁用 |
| 成功 | 接口成功 | 成功提示 + 跳转 | - |
| 业务失败 | 接口返回 409 | 字段错误就近显示 | 保留输入 |
| 网络失败 | 请求超时 | 顶部错误提示 + 重试 | 保留输入 |
| 字段错误 | 前端校验失败 | 字段下方红字 | 提交按钮可点 |

**页面状态表（详情页）：**

| 状态 | 触发条件 | 界面表现 |
|------|---------|---------|
| 加载中 | 请求发出 | 骨架屏 |
| 不存在 | id 无效 | "教材不存在" + 返回列表 |
| 正常 | 有数据 | 详情展示 |
| 错误 | 请求失败 | 错误提示 + 重试 |

- ✅ 提交按钮防重复机制已明确。
