## 四、协作规则

### 4.1 文件命名规则

- 文档：小写英文短横线，如 `candidate-topics.md`
- 代码：Java 用 PascalCase，Vue 用 PascalCase，JS 用 camelCase
- 目录：小写英文短横线

### 4.2 Git 提交规则

- 格式：`<type>: <description>`
- type 包括：`feat`、`fix`、`docs`、`refactor`、`chore`
- 示例：`docs: add candidate topics comparison`

### 4.3 AI 使用规则

- 每次 AI 对话记录到 `project-docs/ai-log.md`
- 记录：日期、目标、提示词摘要、AI 输出、人工修订
- 不把密码、密钥、真实个人信息提供给 AI
