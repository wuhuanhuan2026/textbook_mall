预期结果与人工检查：

异常响应能指出具体原因，不统一写“操作失败”。

失败操作不产生脏数据或部分数据。

前端隐藏按钮与后端拒绝访问同时存在。

常见错误与定位方法：

只写前端提示而无后端规则会被绕过。

异常场景没有 HTTP 状态或业务码时，后续接口难以统一。
