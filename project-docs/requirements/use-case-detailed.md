**用例清单：**

**UC-01：学生购买教材**

| 项 | 内容 |
|----|------|
| 用例编号 | UC-01 |
| 用例名称 | 学生购买教材 |
| 参与角色 | 学生 |
| 前置条件 | 已登录；教材 PUBLISHED；库存充足；余额充足 |
| 主流程 | 1. 浏览教材列表<br>2. 打开详情<br>3. 加入购物车<br>4. 去结算<br>5. 填写收货信息<br>6. 提交订单<br>7. 支付 |
| 备选流程 | 3a. 教材下架，提示"教材未上架"<br>6a. 库存不足，提示"库存不足"<br>7a. 余额不足，提示"余额不足" |
| 异常流程 | 未登录，跳转登录页；重复提交，提示"请勿重复提交" |
| 数据变化 | 新增 Order 记录、OrderItem 记录；Book.stock 减少；User.balance 减少 |
| 完成状态 | 订单状态为 PAID |

**UC-02：管理员发布教材**

| 项 | 内容 |
|----|------|
| 用例编号 | UC-02 |
| 用例名称 | 管理员发布教材 |
| 参与角色 | 管理员 |
| 前置条件 | 已登录；具有 ADMIN 权限 |
| 主流程 | 1. 进入管理后台<br>2. 打开教材管理<br>3. 点击新增<br>4. 填写信息<br>5. 保存草稿<br>6. 上架 |
| 备选流程 | 4a. 字段不完整，提示补充<br>4b. 价格非法，提示"价格必须大于0"<br>4c. 库存负数，提示"库存不能为负数" |
| 异常流程 | 无权限，返回 403 |
| 数据变化 | 新增 Book 记录；状态从 DRAFT 变为 PUBLISHED |
| 完成状态 | 教材可在学生端浏览 |

**UC-03：管理员发货**

| 项 | 内容 |
|----|------|
| 用例编号 | UC-03 |
| 用例名称 | 管理员发货 |
| 参与角色 | 管理员 |
| 前置条件 | 已登录；订单状态为 PAID |
| 主流程 | 1. 进入订单管理<br>2. 筛选"待发货"<br>3. 选择订单<br>4. 点击发货 |
| 备选流程 | 2a. 无待发货订单，显示空状态<br>3a. 订单状态非 PAID，提示"订单状态不正确" |
| 异常流程 | 无权限，返回 403 |
| 数据变化 | Order.status 变为 SHIPPED；记录发货时间 |
| 完成状态 | 学生端订单显示"待收货" |

**预期结果与人工检查：**
- 用例描述的是角色与系统交互，不是代码实现。
- 每个用例有明确结束状态。
- 数据库变化与页面反馈一致。

**实际结果：**
- ✅ 3 个核心用例已编写。
- ✅ 每个用例包含主流程、备选流程、数据变化、完成状态。

**常见错误与定位方法：**
- 用例只写功能名称不能用于测试。
- 漏写前置条件会导致同一步骤在不同状态下结果不一致。
