## 五、降级方案

MVP 不包含"收货地址管理"功能（属于 Should），但"提交订单"需要收货地址。降级方案：

| 方案 | 说明 | 采用 |
|------|------|------|
| 方案1 | 提交订单时手工填写收货信息 | ✅ 采用 |
| 方案2 | 默认地址硬编码 | - |
| 方案3 | 提前实现地址管理 | - |

**采用方案1：** 提交订单页面提供"收货人姓名、电话、地址"三个输入框，手工填写。地址管理功能在 Should 阶段实现。
