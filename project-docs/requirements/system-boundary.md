
系统边界说明：



系统内部：

教材管理（发布、编辑、上下架）

分类管理

购物车管理

订单管理

用户管理

收货地址管理

余额管理（模拟）



外部依赖：

依赖	用途	失败影响	替代方案
MySQL 5.7	数据持久化	系统不可用	无
Redis	缓存、Token 存储	缓存失效	直接查数据库
Nacos 2.2.3	服务注册与发现	服务不可用	静态路由
教材封面图片	静态资源	显示占位图	使用默认图




系统不处理：

真实支付接口对接（仅模拟余额支付）

短信通知

邮件通知

真实校园统一认证

用户收藏功能

优惠券、积分

移动端 App

微信小程序

用户信息	用户注册	用户
