
用户角色表：

角色	代码	描述	主要能力
游客	GUEST	未登录的访问者	浏览已上架教材、搜索教材
学生	STUDENT	注册用户	浏览、搜索、购买、查看订单、管理地址
管理员	ADMIN	后台操作者	发布教材、管理分类、查看订单、批量发货



权限矩阵：

操作	游客	学生	管理员
浏览已上架教材	允许	允许	允许
搜索教材	允许	允许	允许
加入购物车	禁止	仅本人	禁止
提交订单	禁止	仅本人	禁止
查看订单	禁止	仅本人	允许
管理收货地址	禁止	仅本人	禁止
发布教材	禁止	禁止	允许
管理用户	禁止	禁止	允许
管理分类	禁止	禁止	允许
批量发货	禁止	禁止	允许
导出订单	禁止	禁止	允许




越权访问的预期响应：

场景	响应
未登录访问保护接口	401 Unauthorized
学生访问管理接口	403 Forbidden
学生查看他人订单	403 Forbidden
学生修改他人地址	403 Forbidden
预期结果与人工检查：

游客只能浏览已上架教材。

学生不能进入管理端，也不能修改他人订单。

管理员可以管理教材和查看订单。




实际结果：

✅ 3 个角色已识别。

✅ 权限矩阵已建立（11 个操作 × 3 角色）。

✅ 越权响应已定义。




常见错误与定位方法：

只隐藏按钮不能实现后端权限，应在后续保留接口校验任务。

角色名称和数据库枚举不一致时立即统一。
