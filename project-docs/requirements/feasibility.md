**总课时：** 96 学时（8 周）
**每周可用：** 约 12 学时
**结论：** 足够完成教材商城系统的核心功能。

**已完成：**
- 项目环境搭建（实训 2）
- 后端多模块骨架（11 个微服务）
- 前端 Vue 3 工程骨架

## 三、数据可行性

- 教材数据：可自行构造，无需外部授权
- 用户数据：使用测试账号，不涉及真实个人信息
- 图片数据：使用占位图或公开教材封面

**结论：** 数据来源合法，可重复构造。

## 四、设备可行性

- 开发环境：Windows 10/11 个人电脑
- 演示环境：本机启动，无需付费服务器
- 数据库：本地 MySQL

**结论：** 演示不依赖付费服务器或专用硬件。

## 五、合规可行性

- 不使用真实校园统一认证接口
- 不使用真实支付接口
- 不采集手机号、身份证号等敏感信息
- 测试账号使用虚构数据

**结论：** 符合数据最小化和隐私保护原则。

## 六、风险与替代方案

| 风险 | 影响 | 替代方案 |
|------|------|---------|
| 微服务架构复杂 | 学习成本高 | 简化模块数量，先完成核心 5 个模块 |
| Nacos 启动失败 | 服务无法注册 | 使用静态路由替代 |
| Redis 不可用 | 缓存失效 | 直接查数据库 |
| 前端构建失败 | 无法部署 | 使用 Vite 开发模式 |

## 七、最终结论

**选题可行。** 教材商城系统可在本机完成开发、测试和演示，覆盖完整的软件开发流程，满足实训要求。
