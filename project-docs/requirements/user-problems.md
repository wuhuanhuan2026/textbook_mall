# 目标用户与问题说明

## 一、目标用户

| 角色 | 描述 | 主要诉求 |
|------|------|---------|
| 游客 | 未登录的访问者 | 浏览教材信息、了解价格和库存 |
| 学生 | 注册用户 | 购买教材、查看订单、管理地址 |
| 管理员 | 后台操作者 | 发布教材、管理分类、查看订单 |

## 二、真实问题描述

### 问题1：教材信息分散

**现状：** 教材信息分散在多个渠道（班级群、公告栏、教师口头通知），学生难以集中查看。

**影响：** 学生需要反复询问才能确认教材名称、价格和是否有货。

**可观察描述：** 学生打开一个页面即可看到所有已上架教材的标题、作者、价格和库存。

### 问题2：购买流程不清晰

**现状：** 购买教材靠线下登记或人工统计，学生不知道是否购买成功。

**影响：** 学生无法追踪订单状态。

**可观察描述：** 学生提交订单后能在"我的订单"页面看到订单状态（待付款/待发货/待收货/已完成/已取消）。

### 问题3：管理员工作重复

**现状：** 管理员需要手工记录每笔订单，容易出错。

**影响：** 订单管理效率低，容易出现统计错误。

**可观察描述：** 管理员在后台可以按状态筛选订单、批量发货、导出数据。
